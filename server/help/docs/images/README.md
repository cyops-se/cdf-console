# Images for Documentation

Place your documentation images (PNG, JPG, GIF, etc.) in this folder.

## Example

To add a dashboard screenshot:
1. Place the file: `dashboard-overview.png` in this folder
2. Reference it in markdown: `![Dashboard Overview](images/dashboard-overview.png)`

## Supported Formats

- PNG (.png)
- JPEG (.jpg, .jpeg)
- GIF (.gif)
- SVG (.svg)

Images will be embedded in the Go binary and served via the help API.
